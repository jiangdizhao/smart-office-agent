# Smart Office demo music

Place exhibition-safe local audio files in this directory, or set the Backend environment variable:

```powershell
$env:SMART_OFFICE_MUSIC_DIRECTORY = "D:\SmartOfficeMedia\Music"
```

Supported extensions: `.mp3`, `.wav`, `.m4a`, `.flac`, `.wma`, `.aac`, `.ogg`.

Do not commit copyrighted commercial recordings to the repository unless you have permission to distribute them.
